# ADR 005: Tailwind CSS for styling

## Status
Accepted

## Context
Need a utility-first CSS framework that's fast to develop with and produces small production bundles.

## Decision
Use Tailwind CSS with Vite.

## Consequences
- ✅ Rapid UI development
- ✅ Small production CSS (purged unused)
- ✅ Consistent design system
- ✅ No context switching between HTML/CSS
- ✅ Mobile-first responsive utilities
- ⚠️ Learning curve for utility classes
- ⚠️ HTML can become verbose
