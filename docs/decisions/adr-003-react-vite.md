# ADR 003: React + Vite for frontend

## Status
Accepted

## Context
Need a modern, fast frontend framework with good TypeScript support.

## Decision
Use React 18 with Vite as the build tool.

## Consequences
- ✅ Fast dev server with HMR
- ✅ Optimized production builds
- ✅ Excellent TypeScript support
- ✅ Large ecosystem and community
- ✅ Easy migration from CRA
- ⚠️ Requires modern browser targets
